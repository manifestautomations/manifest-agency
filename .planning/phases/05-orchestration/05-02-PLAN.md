<task type="auto">
  <name>Task 2: Create dependency graph builder</name>
  <files>scripts/orchestrator/graph.sh</files>
  <action>
Create dependency graph helper that builds and analyzes issue dependencies.

Functions to implement:

1. `build_dependency_graph()` - Queries GitHub, extracts dependency edges
   - Query open issues with bodies: `gh issue list --state open --json number,body`
   - Extract "Blocked by #N" patterns using jq
   - Output format: "dependency issue" per line (tsort input format)
   - Handle case where no dependencies exist

2. `get_execution_order()` - Returns topological sort of issues
   - Pipe graph to tsort
   - Handle cycle detection (tsort exits non-zero on cycle)
   - Return error message if cycle detected
   - Return issue numbers in execution order if valid

3. `get_ready_issues()` - Returns issues with no unresolved dependencies
   - Query all open issues
   - Filter to those with no blockers OR all blockers are closed
   - These are dispatchable immediately

4. `detect_cascade()` - Given failed issue, find all dependents
   - Search for issues with "Blocked by #N" in body
   - Used for failure cascade handling (from RESEARCH.md Pitfall 6)

Implementation notes:
- Use gh CLI with --json and jq (existing patterns from Phase 2)
- Handle edge case of empty graph (no dependencies)
- tsort is POSIX standard (from RESEARCH.md Standard Stack)

Example from RESEARCH.md:
```bash
build_dependency_graph() {
  gh issue list --state open --json number,body --jq '.[] |
    select(.body | contains("Blocked by #")) |
    # ... extract edges
  '
}
```
