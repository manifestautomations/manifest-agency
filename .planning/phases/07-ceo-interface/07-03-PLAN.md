  <files>.claude/skills/ceo-dashboard/scripts/approval-workflow.sh</files>
  <action>
    Create bash library following lock.sh and audit.sh patterns:

    ```bash
    #!/usr/bin/env bash
    # approval-workflow.sh - File-based approval state management
    # Source: Adapted from lock.sh timeout detection pattern
    ```

    Include guard for re-sourcing:
    ```bash
    [[ -n "${_APPROVAL_WORKFLOW_SOURCED:-}" ]] && return 0
    _APPROVAL_WORKFLOW_SOURCED=1
    ```

    Implement functions:

    1. **create_approval_request()**
       - Parameters: approval_type, agent_id, context_json
       - Types: trust_promotion, critical_violation, scope_access, cross_workspace
       - Generate unique approval_id: "approval-$(date +%s%N)"
       - Calculate timeout: 24 hours, EXCEPT critical_violation gets "9999-12-31T23:59:59Z"
       - Write to .worker/approvals/pending/{approval_id}.json
       - Append to .worker/approvals/registry.jsonl
       - Return approval_id

    2. **approve_request()**
       - Parameters: approval_id, justification (optional)
       - Verify pending file exists
       - Add decision metadata: decision=approved, decided_at, justification
       - Atomic mv from pending/ to approved/
       - Append to registry.jsonl with decision
       - Return success/failure

    3. **deny_request()**
       - Parameters: approval_id, reason (optional)
       - Same flow as approve but decision=denied, moves to denied/

    4. **list_pending_approvals()**
       - Return JSON array of all pending approvals
       - Include time_remaining for each (unless critical)
       - Flag stale approvals (< 2 hours remaining)

    Use jq for all JSON construction.
    Handle Windows/MINGW64 date compatibility.
  </action>

<task type="auto">
  <name>Task 2: Add stale detection and auto-deny functions</name>
  <files>.claude/skills/ceo-dashboard/scripts/approval-workflow.sh</files>
  <action>
    Extend approval-workflow.sh with timeout handling:

    1. **check_stale_approvals()**
       - Iterate .worker/approvals/pending/*.json
       - Skip critical_violation types (infinite timeout)
       - Calculate time remaining: timeout_at - now
       - If < 7200 seconds (2 hours): flag as "stale"
       - If < 0 seconds: mark as "expired"
       - Return JSON array with stale status for each

    2. **process_expired_approvals()**
       - Find all expired approvals (time_remaining < 0)
       - Skip critical_violation types
       - Auto-deny with reason "Auto-denied: timeout after 24 hours"
       - Log to registry with auto_denied=true flag
       - Return count of auto-denied

    3. **get_approval_context()**
       - Parameters: approval_id
       - Read pending file and return formatted context
       - Include: type, agent, context, created_at, timeout_at, time_remaining
       - Return null if not found

    Cross-platform timestamp handling:
    ```bash
    # Try GNU date first, fall back to BSD
    get_timestamp_seconds() {
      local ts="$1"
      date -d "$ts" +%s 2>/dev/null || date -j -f "%Y-%m-%dT%H:%M:%SZ" "$ts" +%s
    }
    ```
  </action>
