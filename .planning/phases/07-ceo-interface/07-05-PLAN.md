    ```bash
    # render-dashboard.sh - Render ASCII dashboard from aggregated data
    set -euo pipefail

    SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
    TEMPLATE="${SCRIPT_DIR}/../templates/dashboard-artifact.md"
    ```

    Functions:

    1. **render_progress_bar()**
       - Input: percent (0-100)
       - Output: ASCII progress bar (10 chars)
       - Example: 87% -> "[========= ]"

    2. **render_pending_approvals()**
       - Input: JSON array of pending approvals
       - Output: Formatted bullet list
       - Include type and agent for each

    3. **render_recent_completions()**
       - Input: JSON array of recent completions
       - Output: Formatted bullet list
       - Include description and duration

    4. **render_dashboard()**
       - Run aggregate-status.sh to get data
       - Extract values with jq
       - Substitute into template
       - Output final rendered dashboard

    Template substitution using sed:
    ```bash
    sed -e "s/{{running}}/$running/g" \
        -e "s/{{blocked}}/$blocked/g" \
        -e "s/{{idle}}/$idle/g" \
        -e "s/{{avg_trust}}/$avg_trust/g" \
        -e "s/{{warnings}}/$warnings/g" \
        -e "s/{{critical}}/$critical/g" \
        -e "s/{{completed}}/$completed/g" \
        -e "s/{{total}}/$total/g" \
        -e "s/{{progress_bar}}/$progress_bar/g" \
        -e "s/{{timestamp}}/$timestamp/g" \
        "$TEMPLATE"
    ```

    Handle dynamic sections (pending approvals, recent completions) with marker replacement.
