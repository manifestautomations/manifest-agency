    2. **Archive briefings:**
       - Copy latest.md to history/YYYY-MM-DD.md

    3. **Handle first briefing:**
       - If no last-generated.timestamp, use 24 hours ago
       - Create initial timestamp file

    4. **Add --date flag:**
       - Allow generating briefing for specific date
       - Useful for catching up after absence

    Functions:
    ```bash
    get_last_briefing_time() {
      if [ -f "$WORKER_DIR/briefings/last-generated.timestamp" ]; then
        cat "$WORKER_DIR/briefings/last-generated.timestamp"
      else
        # Default: 24 hours ago
        date -u -d '24 hours ago' +"%Y-%m-%dT%H:%M:%SZ" 2>/dev/null || \
        date -u -v-24H +"%Y-%m-%dT%H:%M:%SZ"
      fi
    }

    archive_briefing() {
      local briefing_file="$1"
      local archive_date
      archive_date=$(date +%Y-%m-%d)
      cp "$briefing_file" "$WORKER_DIR/briefings/history/${archive_date}.md"
    }

    cleanup_old_briefings() {
      find "$WORKER_DIR/briefings/history" -name "*.md" -mtime +30 -delete 2>/dev/null || true
    }
    ```
