<task type="auto">
  <name>Task 2: Create claude-audit CLI tool</name>
  <files>scripts/worker/claude-audit.sh</files>
  <action>
Create a CLI tool for querying audit logs and violations:

```bash
#!/usr/bin/env bash
# claude-audit - Query audit logs and trust status
#
# Usage:
#   claude-audit list [agent] [since]     - List audit events
#   claude-audit violations [agent]       - Show violations
#   claude-audit verify                   - Verify audit chain integrity
#   claude-audit trust-report             - Show trust scores
#   claude-audit explain <command>        - Explain why command was blocked
#   claude-audit incident <id>            - Show incident details
#   claude-audit timeline <issue>         - Show timeline for issue
```

**Commands to implement:**

1. `list [agent] [since]` - List audit events
   - Filter by agent if provided
   - Filter by date if since provided (YYYY-MM-DD)
   - Output: timestamp, event_type, agent, command (tabular)

2. `violations [agent]` - Show violations
   - List from *-violations.jsonl files
   - Filter by agent if provided
   - Output: timestamp, agent, severity, command, reason (tabular)

3. `verify` - Verify audit chain
   - Source audit.sh and call verify_audit_chain
   - Output success or error with details

4. `trust-report` - Show trust scores
   - Read trust-scores.json
   - Output: agent, score, status, last_violation (tabular)

5. `explain <command>` - Explain blocked command
   - Find most recent command_blocked event matching command
   - Show full details including reason and alternatives

6. `incident <id>` - Show incident details
   - Read .worker/violations/incident-{id}.json
   - Pretty print with jq

7. `timeline <issue>` - Show timeline for issue
   - Read logs/issue-{N}-*.jsonl
   - Sort chronologically
   - Show events related to the issue

**Implementation:**
- Use jq for JSON queries
- column -t for tabular output
- Help message with usage examples
- Exit codes: 0 success, 1 error, 2 invalid args
  </action>
