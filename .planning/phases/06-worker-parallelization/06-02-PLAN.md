Create `scripts/worker/lib/subagent-scope.sh` with these functions:

1. `generate_agent_id()` - Generate hierarchical agent identity:
   - Inputs: parent_id (empty for root), wave_num, task_name
   - Format: `{parent_id}/w{wave}-{task_slug}-{short_hash}`
   - Root format (no parent): `worker-{short_hash}`
   - task_slug: lowercase, hyphens, alphanumeric only
   - short_hash: 8 chars from SHA-256 of PID + timestamp + random
   - Examples from CONTEXT.md:
     - `worker-a1b2c3` (root)
     - `worker-a1b2c3/w2-user-model-x7f3` (sub-agent)
     - `worker-a1b2c3/w2-user-model-x7f3/w1-validation-q2n5` (sub-sub-agent)

2. `get_agent_depth()` - Extract depth from agent ID:
   - Count '/' characters in ID
   - 0 = root worker, 1 = sub-agent, 2 = sub-sub-agent
   - Return numeric depth

3. `check_nesting_limit()` - Enforce max depth of 2:
   - Input: current agent_id
   - Per CONTEXT.md: Depth 3+ is forbidden
   - Return 0 if spawning allowed, 1 if at limit
   - Log error message when limit reached

4. `slugify_task_name()` - Helper to create URL-safe slug:
   - Lowercase, replace spaces/underscores with hyphens
   - Remove non-alphanumeric except hyphens
   - Truncate to reasonable length (30 chars)

Header should include:
- Shebang: #!/usr/bin/env bash
- set -euo pipefail

<task type="auto">
  <name>Task 2: Add constraint derivation and context bundling</name>
  <files>scripts/worker/lib/subagent-scope.sh</files>
  <action>
Add these functions to subagent-scope.sh:

1. `derive_subagent_constraints()` - Layer constraints from parent:
   - Inputs: parent_constraints_file (JSON), task_declared_scope (JSON string)
   - Process per CONTEXT.md:
     a. Load parent constraints (ceiling - cannot exceed)
     b. Apply task-declared scope (narrowing)
     c. Validate: task scope must be subset of parent scope
     d. Return 1 if escalation detected (task exceeds parent)
   - Output: JSON to stdout with derived constraints:
     ```json
     {
       "scope": {"read": [...], "write": [...]},
       "trust_level": N,
       "parent_ceiling": {"write": [...]},
       "agent_id": "...",
       "depth": N
     }
     ```

2. `validate_scope_subset()` - Check scope is subset of parent:
   - Inputs: child_scope (JSON array), parent_scope (JSON array)
   - Use comm or jq to compare sorted arrays
   - Return 0 if valid subset, 1 if exceeds parent
   - Log specific files that exceed scope on failure

3. `create_context_bundle()` - Build context for sub-agent:
   - Inputs: agent_id, task_json, constraints_json
   - Output directory: .worker/agents/{agent_id}/
   - Create files per CONTEXT.md:
     - context.json: task specifics, relevant files
     - constraints.json: derived constraints
     - parent_summary.md: brief orientation text
   - Return path to context directory

4. `register_agent()` - Track agent in registry:
   - Create/update .worker/agents/registry.yaml
   - Record: agent_id, parent_id, status (spawned), timestamp
   - Use yq for YAML manipulation

Error handling:
- Parent constraints file missing: log error, return 1
- Invalid JSON: log parse error, return 1
- Scope escalation: log specific violation, return 1
  </action>

4. Verify register_agent updates registry.yaml

  </verify>
  <done>
