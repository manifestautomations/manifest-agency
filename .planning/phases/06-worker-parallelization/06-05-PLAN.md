Create `scripts/worker/aggregate-wave.sh` with these functions:

1. `aggregate_wave_results()` - Collect results from completed sub-agents:
   - Input: wave_id
   - Load agent list from .worker/waves/{wave_id}/agents.json
   - Filter to status == "complete"
   - Call verify_wave_outputs for structural check
   - Stage all files in each agent's write_scope
   - Return 0 if all outputs present, 1 if missing

2. `verify_wave_outputs()` - Structural verification:
   - Input: wave_id, completed_agents
   - For each agent, check expected_outputs exist
   - Per CONTEXT.md verification pipeline, check:
     a. Structural: all expected outputs present
     b. Syntactic: code parses (use appropriate linters)
   - Return 0 if valid, 1 if issues
   - Log specific missing/invalid files

3. `create_wave_commit()` - Commit all staged changes:
   - Input: wave_num, completed_agents
   - Build commit message per CONTEXT.md format:
     ```
     feat({scope}): {summary}

     Wave {N} parallel execution:
     - [{agent-slug}] {summary}
     - [{agent-slug}] {summary}

     Phase: {phase} | Wave: {wave} | Duration: {duration}
     Worker: {worker_id}
     ```
   - Execute git commit with heredoc for message
   - Return 0 on success, 1 on failure

4. `rollback_wave()` - Undo staged changes on failure:
   - Input: wave_id
   - Get list of staged files: git diff --cached --name-only
   - Unstage all: git reset HEAD $files
   - Restore to pre-wave state: git checkout -- $files
   - Per CONTEXT.md: "On failure: Unstage and restore, no history pollution"

5. `handle_wave_failure()` - Let-finish with salvage:
   - Input: wave_id, failed_agent
   - Per CONTEXT.md: let running agents complete (no cancellation)
   - Assess which completed work is salvageable
   - If salvageable: aggregate partial, retry failed only
   - If not salvageable (dependencies broken): rollback entire wave
   - Pattern from RESEARCH.md handle_wave_failure example

CLI interface:
- --aggregate WAVE_ID: aggregate and commit
- --rollback WAVE_ID: rollback wave
- --verify WAVE_ID: verify only (no commit)
