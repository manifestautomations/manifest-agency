  <name>Task 1: Create dispatch routing script</name>
  <files>scripts/dispatch/dispatch-to-workspace.sh</files>
  <action>
Create `scripts/dispatch/dispatch-to-workspace.sh` with two exported functions:

1. `dispatch_to_workspace(workspace_target, task_description, [parent_agent])`:
   Main dispatch function that:

   a) Resolve workspace name:
      - Call resolve_workspace "$workspace_target"
      - If resolution fails (exit 1), call suggest_workspace and show suggestions
      - Format: "Workspace 'X' not found. Did you mean: ..." (list up to 5 suggestions)
      - Return 1 on resolution failure

   b) Check workspace health:
      - Call check_workspace_health on resolved path
      - Sets HEALTH_STATUS and HEALTH_ISSUES (from 08-02)
      - If RED: show issues, prompt "Proceed anyway? (y/N)", return 1 if user declines
      - If YELLOW: show warning but proceed

   c) Get trust ceiling:
      - Read from `.worker/config.json` using jq: `.guardrails.default_trust_level`
      - Default to 2 if not found

   d) Log dispatch event:
      - Generate dispatch_id: "workspace-dispatch-$(date +%s%N)-$$"
      - Append to `.worker/dispatch/dispatch.jsonl` with extended format:
        ```json
        {
          "timestamp": "ISO8601",
          "event_type": "workspace_dispatch",
          "event_id": "dispatch_id",
          "data": {
            "workspace_id": "basename of path",
            "workspace_path": "absolute path",
            "parent_agent": "parent_agent or 'ceo'",
            "trust_ceiling": N,
            "task_description": "task text",
            "health_status": "GREEN|YELLOW|RED"
          }
        }
        ```

   e) Record frecency access:
      - Call record_workspace_access with workspace_id

   f) Output dispatch confirmation:
      - "Dispatched to workspace: <name>"
      - "Path: <path>"
      - "Task: <description>"
      - "Trust ceiling: Level N"
      - "Health: <status>"

   Return 0 on success.

2. `get_target_workspace([explicit_target])`:
   Intelligent target selection:

   a) If explicit_target provided and non-empty:
      - Return it directly (caller handles resolution)

   b) If no explicit target:
      - Call rank_workspaces_by_frecency
      - Get top workspace (most frequent/recent)
      - If found, prompt: "No target specified. Most frequent: <name>. Use this? (Y/n)"
      - Return selected workspace or empty on decline

   Note: Context extraction from conversation is deferred (Claude's discretion per CONTEXT.md).

Script structure:
```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
REPO_ROOT="$(cd "$SCRIPT_DIR/../.." && pwd)"

# Source dependencies
source "$REPO_ROOT/scripts/workspace/workspace-resolve.sh"
source "$REPO_ROOT/scripts/workspace/workspace-health.sh"
source "$REPO_ROOT/scripts/workspace/workspace-frecency.sh"
source "$SCRIPT_DIR/fuzzy-match.sh"

# ... functions ...

if [[ "${BASH_SOURCE[0]}" == "${0}" ]]; then
    dispatch_to_workspace "$@"
fi
```

Handle edge cases:
- Empty workspace target (call get_target_workspace first)
- Missing config.json (default trust ceiling)
- jq not installed (graceful error message)
- Non-interactive mode (skip prompts, fail on RED)
