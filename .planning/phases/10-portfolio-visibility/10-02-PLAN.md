  <files>scripts/portfolio/portfolio-dashboard.sh</files>
  <action>
Create scripts/portfolio/portfolio-dashboard.sh that renders an ASCII dashboard from portfolio status data.

Script structure:
1. Standard header with usage documentation
2. SCRIPT_DIR and REPO_ROOT resolution
3. Source portfolio-status.sh

Health indicator formatting:
- GREEN: `[OK]` with green ANSI color if terminal supports it (or plain text)
- YELLOW: `[!!]` with yellow ANSI color
- RED: `[XX]` with red ANSI color
- Use tput for color if available, fallback to plain text

Functions to implement:

**format_health_indicator():**
- Parameter: health_status (GREEN, YELLOW, RED)
- Check if terminal supports colors: `tput colors 2>/dev/null || echo 0`
- If colors >= 8:
  - GREEN: `\033[32m[OK]\033[0m`
  - YELLOW: `\033[33m[!!]\033[0m`
  - RED: `\033[31m[XX]\033[0m`
- Else: plain `[OK]`, `[!!]`, `[XX]`
- Return formatted string

**format_frecency_display():**
- Parameter: frecency_score
- If score > 50: "Active"
- If score > 10: "Recent"
- If score > 0: "Idle"
- Else: "New"

**render_needs_attention_section():**
- Parameter: portfolio_data JSON
- Extract items where health == "RED" or pending > 0
- If empty, return empty string (section collapses)
- Output markdown table:
  ```
  ## Needs Attention

  | Project | Status | Pending | Action |
  |---------|--------|---------|--------|
  | name    | [XX]   | 3       | [View] |
  ```
- Use jq to iterate and format

**render_all_projects_section():**
- Parameter: portfolio_data JSON (already sorted by frecency)
- Output markdown table:
  ```
  ## All Projects

  | Project | Health | Activity | Pending |
  |---------|--------|----------|---------|
  | name    | [OK]   | Active   | 0       |
  ```

**render_portfolio_dashboard():**
- Get data: portfolio_data=$(collect_portfolio_status)
- If --force flag, set FORCE_REFRESH=true before calling
- Check cache status from portfolio_data meta
- Build output:
  1. Header: `# Portfolio Dashboard`
  2. Timestamp line with cache indicator
  3. render_needs_attention_section (if non-empty)
  4. render_all_projects_section
  5. Summary line: "Total: N projects | M need attention"
- Output to stdout or file

**render_portfolio_summary_line():**
- Parameter: portfolio_data
- Count total workspaces
- Count needs_attention items
- Format: "Total: N projects | M need attention"

CLI interface:
- No args: render to stdout
- `-o FILE` or `--output FILE`: render to file
- `--force`: force refresh (skip cache)
- `--no-color`: disable ANSI colors
- `help`: show usage

Direct execution block with set -euo pipefail inside the if block.

Export functions: render_portfolio_dashboard

Create scripts/portfolio/README.md documenting the portfolio scripts.

Structure:
```markdown
# Portfolio Scripts

Scripts for aggregating and displaying status across all managed workspaces.

## Scripts

### portfolio-status.sh

Collects status data from all registered workspaces.

**Usage:**
\`\`\`bash
# Get JSON status (default)
bash scripts/portfolio/portfolio-status.sh

# Force refresh (skip cache)
bash scripts/portfolio/portfolio-status.sh --force

# Get only needs-attention items
bash scripts/portfolio/portfolio-status.sh --needs-attention
\`\`\`

**Output format:**
\`\`\`json
{
  "workspaces": [
    {
      "name": "project-name",
      "path": "projects/project-name",
      "health": "GREEN|YELLOW|RED",
      "frecency": 42,
      "pending": 0,
      "last_activity": 1234567890
    }
  ],
  "timestamp": "2026-01-30T12:00:00Z"
}
\`\`\`

**Health status:**
- GREEN: Healthy workspace, recent activity
- YELLOW: Stale (no activity for 3+ days) OR has warnings
- RED: Trust violations OR broken workspace state

**Sourcing:**
\`\`\`bash
source scripts/portfolio/portfolio-status.sh
data=$(collect_portfolio_status)
\`\`\`

### portfolio-dashboard.sh

Renders ASCII dashboard from portfolio status.

**Usage:**
\`\`\`bash
# Display dashboard
bash scripts/portfolio/portfolio-dashboard.sh

# Output to file
bash scripts/portfolio/portfolio-dashboard.sh -o dashboard.md

# Force refresh
bash scripts/portfolio/portfolio-dashboard.sh --force

# Disable colors
bash scripts/portfolio/portfolio-dashboard.sh --no-color
\`\`\`

**Dashboard sections:**
1. **Needs Attention** - Projects with RED health or pending items (collapses if empty)
2. **All Projects** - Full project list sorted by frecency

## Dependencies

- scripts/workspace/workspace-list.sh
- scripts/workspace/workspace-health.sh
- scripts/workspace/workspace-frecency.sh
- jq (JSON processing)

## Cache

Portfolio status is cached in \`.worker/cache/portfolio-cache.json\` with 5-minute TTL.
Use \`--force\` to bypass cache.
```
