<task type="auto">
  <name>Task 2: Create workspace name resolution script</name>
  <files>
    scripts/workspace/workspace-resolve.sh
  </files>
  <action>
1. Create `scripts/workspace/workspace-resolve.sh`:
   - Accept workspace name as argument: `workspace-resolve.sh <name>`
   - Resolution order:
     a. Check if exact directory exists at `projects/<name>/`
     b. Check .gitmodules for submodule with matching path suffix
     c. Check aliases in config.json (case-insensitive using `${var,,}`)
   - On success: print absolute path to workspace, exit 0
   - On failure: print "Workspace 'X' not found" to stderr, list valid workspaces, exit 1
   - Use `shopt -s nocasematch` for case-insensitive alias matching
   - Use `jq -c '.workspaces.aliases[]'` to iterate aliases from config
   - Source pattern from RESEARCH.md Pattern 3
   - Do NOT implement fuzzy matching (user decision in CONTEXT.md: exact match only)

2. Add function `resolve_workspace()` that can be sourced by other scripts:
   - Return 0 on success with path printed to stdout
   - Return 1 on failure with error message to stderr

3. Update `scripts/workspace/README.md` with workspace-resolve.sh usage
  </action>
  <verify>
    Run: `bash scripts/workspace/workspace-resolve.sh nonexistent`
    Expected: Error message with list of valid workspaces, exit code 1
    Run: `bash scripts/workspace/workspace-resolve.sh projects` (if projects dir exists)
    Expected: Returns path or appropriate error
  </verify>
  <done>
    workspace-resolve.sh resolves workspace names and aliases to absolute paths.
    Invalid names fail with helpful "valid workspaces" suggestions.
    Case-insensitive alias matching works.
  </done>
</task>
