<task type="auto">
  <name>Task 2: Create workspace bootstrap script</name>
  <files>
    scripts/workspace/workspace-bootstrap.sh
  </files>
  <action>
1. Create `scripts/workspace/workspace-bootstrap.sh`:
   - Accept workspace name as argument: `workspace-bootstrap.sh <name>`
   - Default location: `projects/<name>/`
   - Optional flag `--path <custom-path>` for non-standard location

2. Bootstrap workflow (from RESEARCH.md Pattern 5):
   a. Check if workspace already exists at path
      - If exists and valid: "Already a valid workspace"
      - If exists but invalid: Offer to scaffold missing structure
      - If not exists: Create new workspace

   b. Read parent trust ceiling from `.worker/config.json`:
      ```bash
      parent_ceiling=$(jq -r '.guardrails.default_trust_level' .worker/config.json)
      ```

   c. Create directory structure:
      - `.planning/`
      - `.claude/`
      - `.claude/commands/`
      - `.claude/skills/`
      - `src/` (optional, common convention)

   d. Copy and substitute templates:
      - Copy `templates/workspace/trust-ledger.md` to `.planning/trust-ledger.md`
      - Copy `templates/workspace/CLAUDE.md` to `CLAUDE.md`
      - Copy `templates/workspace/README.md` to `README.md`
      - Replace `{{WORKSPACE_NAME}}` with actual workspace name
      - Replace `{{TRUST_CEILING}}` with parent ceiling
      - Replace `{{DATE}}` with current date (YYYY-MM-DD)
      - Use `sed` for substitution

   e. Initialize git repository if not already:
      - `git init` if no .git present
      - Create initial commit with structure

   f. Validate using workspace-validate.sh:
      - If validation fails after bootstrap: ERROR, something went wrong
      - If validation passes: SUCCESS

3. Handle existing workspace case:
   - Use workspace-validate.sh to check structure
   - If invalid, prompt: "Structure incomplete. Scaffold missing? (y/n)"
   - If user declines: exit without changes
   - If user accepts: scaffold only missing components

4. Output format:
   ```
   Bootstrapping workspace: <name>
   Trust ceiling (inherited): Level <N>

   Creating structure...
     [OK] .planning/
     [OK] .planning/trust-ledger.md
     [OK] .claude/
     [OK] CLAUDE.md
     [OK] README.md

   Validating...
     [OK] Structure valid

   Workspace bootstrapped successfully.
   Next: git submodule add <url> projects/<name>
   ```

5. Error handling:
   - Path exists but is not a git repo and has files: ABORT (don't overwrite)
   - Permission denied: ABORT with clear message
   - Template files missing: ABORT with message to check templates/workspace/

6. Update README.md with bootstrap usage and examples
