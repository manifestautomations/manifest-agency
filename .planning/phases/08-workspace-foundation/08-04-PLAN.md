<root_cause>
When bash scripts are sourced (`source script.sh && function_name`), the `set -euo pipefail` at the top level propagates to the parent shell. Then any `return 1` in exported functions causes the parent shell to exit immediately.

The fix: Move `set -euo pipefail` inside the direct-execution check block so it only applies when scripts are run directly (`./script.sh`), not when sourced.
</root_cause>
