## Project Status Definitions

| Status | Description |
|--------|-------------|
| **Planning** | Gathering requirements, creating BRIEF and ROADMAP |
| **Active** | In development, has current phase work |
| **Paused** | Temporarily suspended, context preserved |
| **Review** | Awaiting human review or approval |
| **Completed** | All phases done, in maintenance mode |
| **Archived** | No longer active, preserved for reference |

---

## Priority Levels

| Priority | Description |
|----------|-------------|
| **P0** | Critical - requires immediate attention |
| **P1** | High - primary focus for current sprint |
| **P2** | Medium - scheduled for near-term |
| **P3** | Low - backlog, work when capacity allows |

## Project Template

When adding a new project, copy this template:

```markdown
### [Project Name]
- **Path**: `projects/project-name/`
- **Status**: Planning
- **Priority**: P2
- **Lead**: TBD
- **Created**: YYYY-MM-DD
- **Last Activity**: YYYY-MM-DD
- **Current Phase**: 0 - Planning
- **Description**: Brief description of the project purpose
- **Dependencies**: List any dependencies on other projects
- **Notes**: Additional context
```

---

## Quick Reference

### Adding a Project
1. Create project directory: `projects/project-name/`
2. Copy template from `templates/new-project/`
3. Add entry to this registry
4. Create initial BRIEF.md

### Updating Status
1. Update the status in the table above
2. Add entry to the Activity Log below
3. Ensure context/handoff docs are current

### Archiving a Project
1. Change status to Archived
2. Move entry to Archived Projects section
3. Ensure all documentation is complete
4. Create final SUMMARY.md in project
