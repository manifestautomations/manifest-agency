  <name>Task 1: Configure git for submodule workflows</name>
  <files>.gitattributes</files>
  <action>
Configure git repository for safe submodule operations:

1. Set local git configs (run in repo root):
   - `git config submodule.recurse true` (auto-recurse for checkout, pull)
   - `git config push.recurseSubmodules on-demand` (auto-push submodule commits)
   - `git config status.submodulesummary 1` (show submodule changes in status)

2. Create `.gitattributes` for consistent behavior:
   ```
   # Manifest Automations - Git Attributes
   # Normalize line endings for cross-platform consistency
   * text=auto eol=lf

   # Keep shell scripts with LF even on Windows
   *.sh text eol=lf

   # Binary files
   *.png binary
   *.jpg binary
   *.ico binary

   # YAML files (agent manifests)
   *.yaml text eol=lf
   *.yml text eol=lf

   # JSON files
   *.json text eol=lf
   ```

Note: These configs are local to this repo, not global. They ensure consistent behavior without affecting user's global git settings.
  </action>
  <verify>Run `git config --local --list | grep -E "(submodule|push.recurse|status.submodule)"` and confirm all three settings are present.</verify>
  <done>Git configured with submodule.recurse=true, push.recurseSubmodules=on-demand, status.submodulesummary=1, and .gitattributes exists with line ending normalization.</done>
</task>
