<task type="auto">
  <name>Task 2: Configure gitignore for worker files</name>
  <files>
    .gitignore
  </files>
  <action>
Add gitignore patterns for worker runtime files to the existing .gitignore file.

Add the following section (append to existing .gitignore):

```
# Worker runtime files (logs and locks are ephemeral)
.worker/logs/*
!.worker/logs/.gitkeep
.worker/locks/*
!.worker/locks/.gitkeep
```

Pattern explanation:
- `.worker/logs/*` ignores all log files (*.jsonl)
- `!.worker/logs/.gitkeep` keeps the directory marker
- `.worker/locks/*` ignores all lock files (issue-*.lock)
- `!.worker/locks/.gitkeep` keeps the directory marker

This pattern is consistent with .cache/github/ handling from Phase 2.
  </action>
