<task type="auto">
  <name>Task 1: Create inbox-integration.sh for Inbox message delivery</name>
  <files>.claude/skills/ceo-dashboard/inbox-integration.sh</files>
  <action>
    Create script that formats and delivers messages to Inbox conversation:

    ```bash
    #!/usr/bin/env bash
    # inbox-integration.sh - Wire skills to Antigravity Inbox conversation
    set -euo pipefail

    SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
    CONFIG_FILE="${SCRIPT_DIR}/../../.worker/config.json"
    INBOX_DIR="${SCRIPT_DIR}/../../.worker/inbox"
    ```

    Functions:

    1. **get_notification_tier()**
       - Input: event_type (critical_violation, blocked_agent, stale_approval, briefing, completion)
       - Output: tier (immediate, delayed, silent)
       - Read from config.json notification_tiers mapping

    2. **should_deliver_now()**
       - Input: tier, ceo_mode (dnd, normal, verbose)
       - Output: true/false
       - DND: only immediate
       - Normal: immediate + delayed
       - Verbose: all

    3. **format_inbox_message()**
       - Input: type, content, actions (optional JSON array)
       - Output: Inbox-formatted markdown with:
         - Header with type badge
         - Content body
         - Action buttons section (if actions provided)
       - Action format: `[Button Label](action://skill/command?params)`

    4. **deliver_to_inbox()**
       - Input: message, tier
       - Create timestamped message file in .worker/inbox/
       - File format: {timestamp}-{type}.md
       - Include metadata header for Inbox parsing

    5. **format_approval_request()**
       - Input: approval_id, type, agent, context
       - Output: Formatted message with:
         - "Approval Required" header
         - Type badge (trust_promotion, critical_violation, etc.)
         - Agent name and context
         - [Approve] and [Deny] action buttons
         - Timeout indicator

    6. **format_briefing_notification()**
       - Input: briefing_path
       - Output: Formatted message with:
         - "Daily Briefing" header
         - Summary stats (completions, blockers count)
         - [View Full Briefing] action button

    7. **format_blocked_status()**
       - Input: blocked_agents array
       - Output: Compact badge format for Inbox status
       - Format: "X agents blocked" with urgency color
  </action>
  <verify>
    bash -n .claude/skills/ceo-dashboard/inbox-integration.sh
    # Verify functions are defined
    grep -c "^[a-z_]*() {" .claude/skills/ceo-dashboard/inbox-integration.sh
  </verify>
  <done>
    Inbox integration script created with message formatting and tier-aware delivery functions.
  </done>
