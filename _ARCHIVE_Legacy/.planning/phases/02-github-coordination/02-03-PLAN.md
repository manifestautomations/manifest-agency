       - `--project <number>` (optional, defaults to 1)

<task type="auto">
  <name>Task 2: Create issue claiming and status update scripts</name>
  <files>scripts/github/issue-claim.sh, scripts/github/issue-update-status.sh</files>
  <action>
    **scripts/github/issue-claim.sh:**

    Create script that claims an issue for an agent:

    1. **Accepts parameters:**
       - `<issue-number>` (required, positional)
       - `--agent <agent-name>` (required)

    2. **Load cached field IDs** from `.cache/github/project-fields.json`:
       ```bash
       CACHE_FILE=".cache/github/project-fields.json"
       if [ ! -f "$CACHE_FILE" ]; then
         echo "Error: Run project-bootstrap.sh first"
         exit 1
       fi
       ```

    3. **Get project item ID** for the issue using GraphQL query

    4. **Update "Claimed By" field** (text field) via GraphQL mutation:
       ```bash
       gh api graphql -f query='
         mutation($projectId: ID!, $itemId: ID!, $fieldId: ID!, $text: String!) {
           updateProjectV2ItemFieldValue(input: {
             projectId: $projectId, itemId: $itemId, fieldId: $fieldId,
             value: { text: $text }
           }) { projectV2Item { id } }
         }' -f projectId="$PROJECT_ID" -f itemId="$ITEM_ID" \
            -f fieldId="$CLAIMED_BY_FIELD_ID" -f text="$AGENT_NAME"
       ```

    5. **Update Status to "Claimed"** via GraphQL mutation (single select field)

    6. **Add claim comment** to issue using template from 02-01

    **scripts/github/issue-update-status.sh:**

    Create script that updates issue status:

    1. **Accepts parameters:**
       - `<issue-number>` (required, positional)
       - `--status <status>` (required: Backlog, Ready, Claimed, "In Progress", "In Review", Done)

    2. **Load field IDs** from cache

    3. **Get project item ID** for issue

    4. **Get option ID** for the requested status value

    5. **Update Status field** via GraphQL mutation

    Both scripts should:
    - Use `set -e`
    - Validate inputs
    - Provide `--help`
    - Handle "issue not in project" error gracefully
  </action>

  </verify>

<task type="auto">
  <name>Task 3: Create structured comment script</name>
  <files>scripts/github/issue-comment.sh</files>
  <action>
    Create `scripts/github/issue-comment.sh` that:

    1. **Accepts parameters:**
       - `<issue-number>` (required, positional)
       - `--message "Human readable message"` (required)
       - `--agent <agent-name>` (optional, for progress metadata)
       - `--status <status>` (optional: claimed, implementing, testing, blocked, complete)
       - `--progress <0-100>` (optional)
       - `--elapsed <time>` (optional, e.g., "5m 23s")
       - `--current-task "Task description"` (optional)
       - `--blockers "Blocker description"` (optional, defaults to "None")

    2. **Build comment body:**
       - If agent metadata provided, use progress-comment.md template
       - Replace placeholders with values
       - If no metadata, just post the message

    3. **Post comment** using `gh issue comment`:
       ```bash
       gh issue comment "$ISSUE_NUMBER" --body "$COMMENT_BODY"
       ```

    4. **Handle special case: blocker**
       - If `--blockers` is not "None", also add `blocked` label:
         ```bash
         gh issue edit "$ISSUE_NUMBER" --add-label "blocked"
         ```

    Example usage:
    ```bash
    # Simple comment
    ./issue-comment.sh 42 --message "Starting work on this issue"

    # Progress update
    ./issue-comment.sh 42 \
      --message "Implementing JWT refresh logic" \
      --agent backend-developer \
      --status implementing \
      --progress 40 \
      --elapsed "8m 15s" \
      --current-task "Writing token rotation"

    # Blocker report
    ./issue-comment.sh 42 \
      --message "Blocked on API credentials" \
      --agent backend-developer \
      --status blocked \
      --blockers "Waiting for Stripe API key from #45"
    ```
  </action>
  <verify>

    - Script contains `gh issue comment` command
    - Script handles `--blockers` flag with label addition
  </verify>
