  <name>Task 1: Create GitHub Actions workflow for status automation</name>
  <files>.github/workflows/project-status.yml</files>
  <action>
    Create `.github/workflows/project-status.yml` that:

    **Triggers:**
    - `pull_request`: opened, ready_for_review, closed (merged)

    **Jobs:**

    1. **update-on-pr-open** (when PR opened or ready for review):
       - Extract linked issue number from PR body (`Closes #N`)
       - Update issue Status to "In Review"
       - Add comment: "PR opened: #PR_NUMBER"

    2. **update-on-pr-merge** (when PR merged):
       - Extract linked issue number
       - Update issue Status to "Done"
       - GitHub's `Closes #N` auto-closes the issue (native feature)
       - Add completion comment with PR link

    **Implementation notes:**

    - Use `secrets.GITHUB_TOKEN` for issue comments (has repo scope)
    - Need `secrets.PROJECT_PAT` for Projects API (needs read:project scope)
    - Or use GitHub App with projects permission

    Since current `gh auth` doesn't have `read:project` scope for GitHub Actions:
    - Document that PROJECT_PAT secret needs to be created
    - Provide instructions for creating PAT with correct scopes

    **Workflow structure:**
    ```yaml
    name: Project Status Automation

    on:
      pull_request:
        types: [opened, ready_for_review, closed]

    jobs:
      update-status:
        runs-on: ubuntu-latest
        if: github.event.pull_request.merged == true || github.event.action != 'closed'
        steps:
          - name: Checkout
            uses: actions/checkout@v4

          - name: Extract issue number
            id: issue
            run: |
              BODY="${{ github.event.pull_request.body }}"
              ISSUE_NUM=$(echo "$BODY" | grep -oP 'Closes #\K\d+' | head -1)
              echo "number=$ISSUE_NUM" >> $GITHUB_OUTPUT

          - name: Update to In Review (PR opened)
            if: github.event.action == 'opened' || github.event.action == 'ready_for_review'
            run: |
              ./scripts/github/issue-update-status.sh ${{ steps.issue.outputs.number }} --status "In Review"
            env:
              GH_TOKEN: ${{ secrets.PROJECT_PAT }}

          - name: Update to Done (PR merged)
            if: github.event.pull_request.merged == true
            run: |
              ./scripts/github/issue-update-status.sh ${{ steps.issue.outputs.number }} --status Done
            env:
              GH_TOKEN: ${{ secrets.PROJECT_PAT }}

          - name: Add completion comment
            if: github.event.pull_request.merged == true
            run: |
              gh issue comment ${{ steps.issue.outputs.number }} --body "Completed via PR #${{ github.event.pull_request.number }}"
            env:
              GH_TOKEN: ${{ secrets.GITHUB_TOKEN }}
    ```

    **Handle edge cases:**
    - PR without "Closes #N" (skip status update, log warning)
    - Issue not in project (scripts should handle gracefully)
    - Rate limiting (GitHub Actions has higher limits)
  </action>
