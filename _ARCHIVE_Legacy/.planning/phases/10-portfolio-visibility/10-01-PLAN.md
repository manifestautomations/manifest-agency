<task type="auto">
  <name>Task 1: Create portfolio status aggregation script</name>
  <files>scripts/portfolio/portfolio-status.sh</files>
  <action>
Create scripts/portfolio/portfolio-status.sh that aggregates status across all workspaces.

Script structure:
1. Standard header with usage documentation
2. SCRIPT_DIR and REPO_ROOT resolution (copy pattern from workspace-health.sh)
3. Source dependencies: workspace-list.sh, workspace-health.sh, workspace-frecency.sh
4. Cache configuration: CACHE_FILE="$REPO_ROOT/.worker/cache/portfolio-cache.json", CACHE_TTL_SECONDS=300

Functions to implement:

**is_portfolio_cache_valid():**
- Return 1 if FORCE_REFRESH=true
- Return 1 if cache file missing
- Return 0 if cache age < CACHE_TTL_SECONDS
- Use cross-platform mtime (stat -c %Y || stat -f %m)

**get_workspace_last_activity(workspace_path):**
- Check .worker/dispatch/dispatch.jsonl in workspace for latest timestamp
- If no dispatch log, check git log --format=%ct -1
- Return epoch timestamp or 0

**is_workspace_stale(last_activity_epoch):**
- Calculate days since last activity
- Return "true" if >= 3 days, "false" otherwise

**collect_portfolio_status():**
- Initialize result='{"workspaces":[],"timestamp":"..."}'
- Get workspaces_json=$(list_workspaces --porcelain)
- For each workspace (jq -c '.[]'):
  - Extract name, path, status
  - Skip if status == "not-initialized"
  - Resolve full_path="$REPO_ROOT/$path"
  - Call check_workspace_health "$full_path"
  - Determine health_display:
    - If HEALTH_STATUS == "RED", health="RED"
    - Else get last_activity, if stale then health="YELLOW" else health=HEALTH_STATUS
  - Get frecency_score=$(calculate_frecency_score "$name")
  - Count pending items in "$full_path/.worker/inbox" (*.md files)
  - Build workspace JSON object with: name, path, health, frecency, pending, last_activity
  - Append to result.workspaces using jq
- Sort workspaces by frecency (descending) using jq sort_by(-.frecency)
- Save to cache if successful
- Output result

**get_needs_attention():**
- Takes portfolio_data as input
- Filter workspaces where health == "RED" or pending > 0
- Return JSON array of attention items

CLI interface:
- `--force`: Set FORCE_REFRESH=true
- `--json`: Output raw JSON (default)
- `--needs-attention`: Output only needs-attention items
- `help`: Show usage

Direct execution block with set -euo pipefail inside the if block (not outside, to avoid affecting sourcing).

Export functions: collect_portfolio_status, get_needs_attention, is_workspace_stale
  </action>

3. If workspaces registered: `bash scripts/portfolio/portfolio-status.sh | jq '.workspaces[0].health'` returns GREEN, YELLOW, or RED
  </verify>
