<task type="auto">
  <name>Task 2: Create workspace health check script</name>
  <files>
    scripts/workspace/workspace-health.sh
  </files>
  <action>
1. Create `scripts/workspace/workspace-health.sh`:
   - Accept optional workspace name/path argument
   - If no argument: check all workspaces (use workspace-list.sh)
   - If argument: check single workspace (use workspace-resolve.sh)

2. Health check stages (from RESEARCH.md Pattern 4):
   Stage 1 - Git state:
   - Not a git repo -> RED
   - Detached HEAD -> YELLOW
   - Uncommitted changes -> YELLOW

   Stage 2 - Structure (uses workspace-validate.sh):
   - Missing trust ledger -> RED
   - Missing .claude directory -> YELLOW

   Stage 3 - Trust ledger validity:
   - Trust ledger format invalid -> YELLOW

3. Health status aggregation:
   - Any RED -> overall RED (blocks dispatch)
   - Any YELLOW (no RED) -> overall YELLOW (warning)
   - All pass -> GREEN

4. Output format for single workspace:
   ```
   Workspace: project-name
   Status: GREEN|YELLOW|RED
   Issues:
     - issue 1 (if any)
     - issue 2 (if any)
   ```

5. Output format for all workspaces (table):
   ```
   Workspace Health Status
   -----------------------
   [OK]   project-a
   [WARN] project-b: uncommitted-changes
   [ERR]  project-c: missing-ledger
   ```

6. Provide functions `check_workspace_health()` and `check_all_workspaces()` that can be sourced

7. Use git plumbing commands:
   - `git rev-parse --abbrev-ref HEAD` (check for detached HEAD)
   - `git diff-index --quiet HEAD` (check for uncommitted changes)
   - Do NOT use `git status` (porcelain, format changes)

8. Update README.md with health check usage and status meanings
  </action>
  <verify>
    Run: `bash scripts/workspace/workspace-health.sh`
    Expected: Shows health status for all workspaces (or message if none)
    Run: `bash scripts/workspace/workspace-health.sh .`
    Expected: Shows health status for current directory
  </verify>
  <done>
    workspace-health.sh reports color-coded health status.
    RED status blocks dispatch with clear explanation.
    YELLOW status warns but allows proceed.
    GREEN status means healthy.
    Works for single workspace or all workspaces.
  </done>
</task>
