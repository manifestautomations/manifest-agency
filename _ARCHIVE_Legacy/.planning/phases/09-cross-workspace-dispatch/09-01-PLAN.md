<task type="auto">
  <name>Task 1: Create frecency tracking script</name>
  <files>scripts/workspace/workspace-frecency.sh, .worker/dispatch/frecency.jsonl</files>
  <action>
Create `scripts/workspace/workspace-frecency.sh` with three exported functions:

1. `record_workspace_access(workspace_id)`:
   - Append JSONL event: `{"timestamp":"ISO8601","workspace_id":"$1","event":"access"}`
   - Use `date -u +%Y-%m-%dT%H:%M:%SZ` for timestamp
   - Append to `.worker/dispatch/frecency.jsonl`

2. `calculate_frecency_score(workspace_id)`:
   - Read events for workspace_id from frecency.jsonl using jq
   - Count total visits
   - Sample last 10 visits, calculate time-decay weights:
     - < 5 days: weight=100
     - 5-14 days: weight=70
     - 15-31 days: weight=50
     - 32-89 days: weight=30
     - 90+ days: weight=10
   - Score = visit_count * (average_weight / 100)
   - Echo score to stdout

3. `rank_workspaces_by_frecency()`:
   - Get unique workspace_ids from frecency.jsonl
   - Calculate score for each
   - Output sorted by score descending (highest first)
   - One workspace_id per line

Script structure:
- Set SCRIPT_DIR and REPO_ROOT (pattern from workspace-resolve.sh)
- Define FRECENCY_LOG as `.worker/dispatch/frecency.jsonl`
- Export functions for sourcing
- Include main guard: `if [[ "${BASH_SOURCE[0]}" == "${0}" ]]; then`

Create empty `.worker/dispatch/frecency.jsonl` if it doesn't exist (touch command in script init or document that dispatch-to-workspace.sh creates it).

Handle edge cases:
- Empty frecency log (return score 0)
- jq parse errors (return 0, continue gracefully)
- Cross-platform date parsing (use simple age calculation in seconds)
  </action>
  <verify>
```bash

# Test ranking
record_workspace_access "test-project"
record_workspace_access "other-project"
rank_workspaces_by_frecency | head -1
```
  </verify>
  <done>record_workspace_access appends JSONL, calculate_frecency_score returns numeric value, rank_workspaces_by_frecency outputs workspace list sorted by score</done>

<task type="auto">
  <name>Task 2: Create fuzzy matching script</name>
  <files>scripts/dispatch/fuzzy-match.sh</files>
  <action>
Create `scripts/dispatch/fuzzy-match.sh` with two exported functions:

1. `levenshtein(str1, str2)`:
   - Bash implementation of Levenshtein distance algorithm
   - Handle shorter string first (swap if str1 < str2 length)
   - Use array-based distance matrix
   - Echo final edit distance to stdout
   - Reference: https://gist.github.com/jq2/5ba5395bfd5aa1647f8cdc419d3f9e41

2. `suggest_workspace(input)`:
   - Threshold = 3 (max edit distance for suggestions)
   - Get all workspace names from:
     a) Projects directory via `ls projects/`
     b) Submodule names from `.gitmodules` via git config
     c) Alias names from `.worker/config.json`
   - For each workspace, calculate Levenshtein distance (case-insensitive)
   - Collect matches where distance <= threshold
   - Sort by distance ascending
   - Output workspace names (one per line, closest first)
   - If no matches, output nothing (empty)

Script structure:
- Set SCRIPT_DIR and REPO_ROOT
- Source workspace-list.sh for list_workspaces function
- Export functions for sourcing
- Include main guard

Handle edge cases:
- Empty input (return nothing)
- No workspaces registered (return nothing)
- Exact match found (still include in suggestions with distance 0)

Create `scripts/dispatch/` directory if it doesn't exist (mkdir -p in script setup).
  </action>
