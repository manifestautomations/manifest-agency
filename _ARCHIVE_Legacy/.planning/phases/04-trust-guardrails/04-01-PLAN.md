  <name>Task 2: Create trust guardrails YAML configuration</name>
  <files>.claude/trust-guardrails.yaml</files>
  <action>
Create the project-level trust guardrails configuration with:

**Version and metadata:**
- version: 1.0.0

**Safety floor (critical patterns - ALWAYS block):**
- `rm -rf /` - Catastrophic filesystem deletion
- `dd if=.* of=/dev/.*` - Disk overwrite
- `mkfs\\..*` - Filesystem formatting
- `curl .* \\| bash` - Remote code execution
- `wget .* \\| bash` - Remote code execution
- `git push --force (main|master)` - Force push to protected branches
- `git reset --hard origin/main` with uncommitted changes
- `chmod -R 777 /` - World-writable root
- `:(){ :|:& };:` - Fork bomb
- `> /dev/sda` - Direct disk write
- `rm -rf ~` - Home directory deletion
- `rm -rf .git` - Git history deletion (when not in .gitignore context)

**Destructive operations (high severity - confirm or block based on trust):**
- `rm -rf .*` - Recursive deletion
- `git reset --hard` - Discard changes
- `git clean -fd` - Delete untracked files
- `git checkout -- .` - Discard working tree changes
- `DROP TABLE` - SQL table deletion
- `DROP DATABASE` - SQL database deletion

**Scope enforcement settings:**
- require_literal_separator: true
- require_literal_leading_dot: true
- deny_tightening_only: true

**Trust levels (0-4) with response mapping:**
- Level 0: block all, no confirmation allowed
- Level 1: confirm high+, block critical
- Level 2: confirm high, allow medium+
- Level 3: allow high, block critical
- Level 4: confirm critical, allow all others

**Violation thresholds:**
- warning: 20 points
- probation: 40 points
- demotion: 60 points
- decay_rate: 5 points per clean action

Use YAML anchors for reusable patterns where appropriate.
  </action>

