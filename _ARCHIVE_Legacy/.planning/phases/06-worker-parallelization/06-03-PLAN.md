   - Use `timeout -k $grace_period $soft_timeout` for two-stage termination

   - Grace = 20% of budget (minimum 5 seconds)
   - Hard = 100% of budget

3. `get_remaining_time()` - Track time elapsed:
   - Uses SECONDS builtin (set at function start)
   - Returns remaining seconds from budget
   - Useful for sub-agents to check their time

4. `format_duration()` - Human-readable duration:
   - Input: seconds
   - Output: "Xm Ys" format for logging
