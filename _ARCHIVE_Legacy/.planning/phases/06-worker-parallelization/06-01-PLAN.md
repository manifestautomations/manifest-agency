  <action>
Create `scripts/worker/lib/graph-parser.sh` with these functions:

1. `extract_execution_graph()` - Extract YAML block from PLAN.md:
   - Find "## Execution Graph" heading
   - Extract content between ```yaml and ``` fences
   - Use sed for markdown parsing (pattern from RESEARCH.md)
   - Return empty with exit 1 if no graph found (serialization fallback)
   - Validate YAML syntax with yq

2. `get_task_dependencies()` - Get dependencies for a specific task:
   - Input: task_id, yaml_block
   - Output: space-separated list of dependency task IDs
   - Use yq: `.tasks[] | select(.id == "$task_id") | .depends_on[]`

3. `get_task_property()` - Generic property accessor:
   - Input: yaml_block, task_id, property_name
   - Output: property value
   - Support: id, name, write_scope, estimated_duration, depends_on

4. `list_all_tasks()` - Get all task IDs from graph:
   - Input: yaml_block
   - Output: newline-separated task IDs

Header should include:
- Shebang: #!/usr/bin/env bash
- set -euo pipefail
- SCRIPT_DIR detection
- Usage documentation

IMPORTANT: Use yq (mikefarah v4.44+) for YAML parsing. Do NOT attempt regex-based YAML parsing - YAML has complex edge cases (multi-line strings, escaping) that require proper parsing.

<task type="auto">
  <name>Task 2: Add DAG validation and ready task detection</name>
  <files>scripts/worker/lib/graph-parser.sh</files>
  <action>
Add these functions to graph-parser.sh:

1. `validate_dag()` - Validate no cycles in dependency graph:
   - Input: yaml_block
   - Convert to tsort input format (IMPORTANT: format is "dependency dependent", NOT "dependent dependency")
   - Run through tsort, check exit code
   - Return 0 if valid DAG, 1 if cycle detected
   - Pattern from scripts/orchestrator/graph.sh lines 66-67

2. `get_ready_tasks()` - Get tasks with no dependencies:
   - Input: yaml_block
   - Output: task IDs where depends_on is null or empty array
   - These are Wave 1 candidates for parallel execution

3. `get_dependent_tasks()` - Get tasks that depend on a given task:
   - Input: task_id, yaml_block
   - Output: task IDs that list task_id in their depends_on
   - Used for cascade detection when a task fails

4. `check_parallelization_threshold()` - Check if parallelization makes sense:
   - Input: yaml_block
   - Per CONTEXT.md: 3+ independent tasks OR 2 tasks with duration > 5 min
   - Output: "parallel" or "serial" recommendation

Add comprehensive error handling:
- Invalid YAML: log error, return 1
- No graph found: log info (not error), return 1
- Cycle detected: log error with cycle hint, return 1
  </action>
  <verify>
1. Create test PLAN.md with known cycle, verify validate_dag fails
2. Create test PLAN.md with valid DAG, verify validate_dag passes
3. Verify get_ready_tasks returns correct tasks
4. Test check_parallelization_threshold with various task counts
5. ShellCheck passes
  </verify>
