<task type="auto">
  <name>Task 2: Remove set -euo pipefail from library files</name>
  <files>
scripts/worker/lib/graph-parser.sh
scripts/worker/lib/scope-validator.sh
scripts/worker/lib/subagent-scope.sh
scripts/worker/lib/timeout-manager.sh
  </files>
  <action>
Remove `set -euo pipefail` from these 4 library files. These files are designed to be SOURCED, not executed directly. When sourced, `set -euo pipefail` applies to the PARENT shell and:

1. `-u` (nounset) causes errors on undefined variables like BP_PIPESTATUS used by some shell prompts
2. `-e` (errexit) can cause the parent shell to exit on command failures
3. `-o pipefail` changes pipeline behavior for the entire parent shell

The functions within these libraries should handle their own error cases internally rather than enforcing strict mode on the sourcing shell.

Specific lines to remove:
- graph-parser.sh: line 37 (`set -euo pipefail`)
- scope-validator.sh: line 2 (`set -euo pipefail`)
- subagent-scope.sh: line 2 (`set -euo pipefail`)
- timeout-manager.sh: line 2 (`set -euo pipefail`)

Do NOT remove the shebang lines (`#!/usr/bin/env bash`) - those are documentation and don't affect sourcing.

Do NOT add any replacement error handling at the top of the files. The individual functions should (and do) handle errors appropriately with explicit checks and return codes.
  </action>
