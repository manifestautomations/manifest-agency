# CEO Dashboard Skill

Display the executive dashboard showing real-time agent status and project health.

## Execution

Generate the executive dashboard by running:

```bash
bash -c 'source .claude/skills/ceo-dashboard/scripts/render-dashboard.sh'
```

Present the output as a code block (preserves ASCII formatting).

## Dashboard Sections

The dashboard displays five key sections:

1. **Agent Status** - Running, blocked, idle counts
2. **Trust Health** - Average level, warnings, critical count
3. **Project Velocity** - Completion rate, average task time
4. **Pending Approvals** - Items needing CEO decision
5. **Recent Completions** - Last completed tasks

If any section shows issues (blocked agents, warnings), offer to show details.

## Script Integration

The dashboard is generated by:

1. **aggregate-status.sh** - Collects metrics from:
   - `.worker/agents/` - Active agent registry
   - `.worker/violations/trust-scores.json` - Trust health
   - `.worker/approvals/pending/` - Pending approvals
   - `.worker/dispatch/dispatch.jsonl` - Velocity metrics

2. **render-dashboard.sh** - Renders collected data into ASCII dashboard format

## Cache Behavior

- **Agent status**: Always fetched live (critical for decision-making)
- **Trust health**: Live fetch (security-sensitive)
- **Project velocity**: 5-minute cache (stable metrics)
- **Pending approvals**: Live fetch (time-sensitive)
- **Recent completions**: 5-minute cache (stable data)

Cache age is shown in the footer.
