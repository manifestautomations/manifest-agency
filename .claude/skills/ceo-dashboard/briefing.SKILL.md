# Daily Briefing Skill

Generate a comprehensive daily briefing for the CEO with actionable insights.

**Manual invocation only** - This skill does not auto-trigger to prevent accidental briefing generation.

## Execution

1. Run the briefing generation script:
   ```bash
   bash .claude/skills/ceo-dashboard/scripts/generate-briefing.sh
   ```

2. If the script doesn't exist yet, manually aggregate from these sources:
   - `.worker/approvals/pending/` - Blockers requiring CEO action
   - `.worker/logs/` - Overnight activity summary
   - `.worker/violations/trust-scores.json` - Health indicators
   - `.planning/STATE.md` - Progress snapshot
   - GitHub issues with milestone labels - Today's outlook

## Briefing Sections

Present sections in **priority order** (blockers first for immediate attention):

### 1. Blockers (Priority: CRITICAL)
Items requiring immediate CEO action:
- Pending approvals with timeout urgency
- Trust violations requiring review
- Failed executions needing decision

For each blocker, include:
- **ID**: Unique identifier for quick reference
- **Type**: Approval / Violation / Failure
- **Summary**: One-line description
- **Urgency**: Time until auto-resolution or escalation
- **Actions**: [Approve] [Deny] [Review] links

### 2. Overnight Summary
Activity since last briefing:
- Tasks completed (success/partial/failed counts)
- Trust events (promotions/demotions/violations)
- New issues created or closed
- Commits pushed to main

### 3. Health Indicators
System health at a glance:
- Agent availability: X of Y agents healthy
- Trust health: Average trust level, violation trend
- Queue depth: Pending tasks, estimated completion
- Resource usage: Active worktrees, lock contention

### 4. Progress Snapshot
Phase and milestone progress:
- Current phase: X% complete (N of M plans)
- Velocity trend: Accelerating / Stable / Slowing
- Blockers impact: Tasks delayed by pending decisions

### 5. Today's Outlook
Recommended focus for the day:
- Priority tasks (highest impact, ready to start)
- Decisions needed (blocking downstream work)
- Risks to watch (potential issues to monitor)

## Section Collapse Rules

- **Empty sections**: Collapse entirely (don't show "None" placeholders)
- **No blockers**: Celebrate with "[OK] No blockers - clear to execute"
- **Zero overnight activity**: Show "Quiet night - no agent activity"

## Archival

After generation, the briefing is archived to:
`.worker/briefings/history/YYYY-MM-DD.md`

Previous briefings available for trend analysis and audit.
