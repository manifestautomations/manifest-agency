# Daily Briefing Skill

Generate a comprehensive daily briefing for the CEO with actionable insights.

**Manual invocation only** - This skill does not auto-trigger to prevent accidental briefing generation.

**Note:** Briefings are automatically delivered to the Inbox conversation.
Running /briefing manually will also deliver to Inbox (with duplicate protection - only one delivery per day).

## Execution

Generate the daily briefing:

```bash
bash -c 'source .claude/skills/ceo-dashboard/scripts/generate-briefing.sh /tmp/ceo-briefing.md'
cat /tmp/ceo-briefing.md
```

Present the briefing content directly (it's already formatted markdown).

If blockers exist, offer to help with approvals via /approve command.

## Briefing Sections

Sections appear in **priority order** (blockers first):

1. **Blockers** - Pending approvals requiring CEO action
   - Type and agent
   - Timeout urgency
   - Action links: [Approve] [Deny]

2. **Overnight Summary** - Activity since last briefing
   - Completions and failures
   - Trust events
   - Milestones reached

3. **Health Indicators** - Only shown if issues exist
   - Average trust level
   - Warning count
   - Critical count

4. **Progress Snapshot** - Always shown
   - Project completion percentage
   - Current velocity
   - Active phase

5. **Today's Outlook** - Only if work queued
   - Queued items
   - Pending items

## Section Collapsing

Empty sections are automatically collapsed to keep briefings concise.
Target length: 25-30 lines for one-screen readability.

## Script Integration

The briefing is generated by **generate-briefing.sh** which:

1. Reads pending approvals from `.worker/approvals/pending/`
2. Parses dispatch log for overnight activity
3. Checks trust scores for health indicators
4. Reads STATE.md for progress snapshot
5. Checks queue for today's outlook

## Archival

After generation, briefings are archived to:
`.worker/briefings/history/YYYY-MM-DD.md`

Previous briefings kept for 30 days for trend analysis.

## Error Handling

- First briefing uses last 24 hours as baseline
- If generation fails, check `.worker/briefings/` permissions

## Options

- **On-demand:** Just run `/briefing` anytime
- **Scheduled:** Configure cron for daily 08:00 (see docs)
