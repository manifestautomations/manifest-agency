# AI Staffing Vertical

This directory contains the documentation for Manifest's "Rising Star" vertical: **AI Recruiting Agents**.

## Strategy
We are moving away from general "Automation" (low ticket) to "Specialized Digital Workers" (high ticket).
Recruiting is the perfect wedge because:
1.  **High Volume:** Agencies get 1000s of resumes.
2.  **High Value:** One placement = $20k fee.
3.  **Broken Process:** Humans screen resumes in 6 seconds (badly).

## Key Files
- `product-spec.md` - Technical architecture for the Ephemeral Recruiter Agent (DeepSeek R1 + Vapi).

## Competitors (2025)
- **HeroHunt.ai** - Autonomous sourcing.
- **Recruiterflow** - AI ATS.
- **Paradox.ai** - Chatbot screening (text only).

## Our Edge
- **DeepSeek R1 (Reasoning):** We don't just match keywords; we reason about "Culture Fit".
- **Vapi.ai (Voice):** We interview candidates via phone, not just text.
- **GraphRAG (Memory):** We understand relationships (ex-Google = Tier 1).
