# Launch Social Media Plan

**Goal:** Drive initial traffic to the new website and validate the "Earned Autonomy" positioning.
**Target:** 1,000 unique visitors in Week 1.

## 1. LinkedIn Strategy (Founder-Led)

**Theme:** "The Agency Model is Dead"
**Frequency:** 1x/day for 5 days.

### Post 1: The Manifesto (Launch Day)
*   **Hook:** "I just fired myself from data entry. You should too."
*   **Body:** Explain the "Efficiency Paradox". Agencies selling hours are doomed. Introduce Manifest Automations.
*   **Visual:** Screenshot of the ROI Calculator.
*   **CTA:** "Check the calculator in the comments."

### Post 2: The Solution (Day 2)
*   **Hook:** "Stop hiring interns to move CSVs."
*   **Body:** Introduce the concept of "Digital Workers" (Level 1-3).
*   **Visual:** The "Trust Level" table from the website.

### Post 3: The Proof (Day 3)
*   **Hook:** "How we saved a dental clinic $4,500/mo with one API call."
*   **Body:** Mini-case study of the Dental Voice Agent.
*   **Visual:** Diagram of the Vapi -> Cal.com flow.

## 2. Twitter/X Strategy (Build in Public)

**Theme:** "Engineering a Scalable Agency"
**Frequency:** 2 threads + daily updates.

### Thread 1: The Stack
*   "We built a pSEO engine for our agency in 4 hours. Here's the stack: Next.js 16 + Tailwind + Vercel + Local Data. 🧵"

### Thread 2: The Automations
*   "Our sales team is a script. Here's how we use Octolens + Apollo + Claude to find leads while we sleep. 🧵"

## 3. Cold Outreach (Dogfooding)

**Theme:** "We built this for ourselves."
**Target:** 50 Agency Owners.
**Channel:** LinkedIn DM / Email.

*   "Hey [Name], I see you're running [Agency]. Are your analysts still manually updating client dashboards? We built a tool to fix that. Want to see the repo?"

## 4. Communities (IndieHackers / Reddit)

*   **r/agency:** "I built an open-source agency website template. Roast it."
*   **IndieHackers:** "Launching a 'Service-as-a-Software' agency. Day 1 stats."
